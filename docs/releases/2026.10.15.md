# Release 2026.10.15

Pinchflat-ngx release notes for the October 2026 publication wave on `master` (through PR **#110**).

## Migration and data

- Legacy Pinchflat migration UI, review flow, and operator guides (**#86**, **#104**).
- Optional automatic SQLite→PostgreSQL migration (**#87**).
- Import existing library files without redownloading (**#85**).
- Recoverable source directory moves (**#109**).
- PostgreSQL text columns for long paths and configuration (**#107**).

## Reliability and operations

- Configurable database timeouts (**#102**).
- Oban cleanup, live source table updates, and media query indexes (**#105**).
- Bandit HTTP adapter and dependency/tooling updates (**#106**, **#108**, **#96**).
- Fixes for indexing health, Apprise links with an external base URL, show URLs, and related source issues (**#84**, **#100–#103**, **#101**).

- Time-format toggle keyboard and styling fixes (**#92**).
