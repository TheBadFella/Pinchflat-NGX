> [!IMPORTANT]
> Pinchflat-ngx is a community fork of Pinchflat, maintained for continued self-hosted use. Module and database names may still say Pinchflat for compatibility.

Hey everyone — thanks for using **Pinchflat-ngx**.

I have been developing this fork on my own for several months now, and I am glad more people are running it. I am always open to suggestions and feature requests from other self-hosters. I want this app to stay smooth, reliable, and useful for the way we actually archive and watch YouTube libraries.

I picked up this work because I like Pinchflat’s UI compared with other YouTube downloaders. Keeping that feel while fixing migration pain and day-to-day bugs is why the fork exists.

If you would like to help, you are welcome to open issues, leave review notes, or send pull requests. I am happy to merge changes after we look at them together.

**This is one of the largest releases so far.** It reflects the issues and ideas you opened, plus the work to support moving from upstream Pinchflat. There was not much public guidance on migrating before; the wiki and docs now walk through backup, review, and cutover. Several problems people hit when switching straight to Pinchflat-ngx without that path are addressed in this wave.

## Migration and library data

- Legacy Pinchflat migration welcome flow, review screen, and operator guides (**#86**, **#104**). Start with [Migrating from Pinchflat](https://github.com/TheBadFella/Pinchflat-NGX/wiki/Migrating-from-Pinchflat) on the wiki.
- Optional in-app SQLite → PostgreSQL migration with review and restart behavior (**#87**).
- Import files already on disk without redownloading (**#85**).
- Recoverable source directory moves with safer failure handling (**#109**).
- PostgreSQL text columns for long paths, descriptions, and related configuration (**#107**).

## Reliability and operations

- Configurable database statement timeouts (**#102**).
- Oban job cleanup, live source table updates, and media query indexes (**#105**).
- Bandit HTTP adapter and dependency / container tooling updates (**#106**, **#108**, **#96**).
- Indexing health, Apprise links when an external base URL is set, YouTube `/show/` URLs, and related source fixes (**#84**, **#100–#103**, **#101**).
- **Download space protection:** pause new downloads when free disk space drops below configurable thresholds, with recovery when space returns (settings, workers, and schema ship together).
- **YouTube client fallback chains:** retry failed downloads with an ordered list of player clients per source when yt-dlp reports a client-specific failure; respects download policy and partial-file behavior.
- **Cookie health warnings:** periodic checks and alerts when YouTube cookies look stale or auth is failing, without logging private cookie contents.

## Playback and streaming

- **Safer media streaming:** corrected byte-range and `HEAD` handling for media playback and clients that probe file size before seeking (Bandit stack on `master`).

## Interface

- Sources header layout and touch targets on small screens (**#110**).
- Time-format toggle keyboard and styling fixes (**#92**).
- **Clearer selects and corners:** improved contrast and corner radius on native `<select>` controls and related form surfaces to match the Material-style UI.
- **Pinchflat-ngx naming in the UI:** user-visible product name, help text, and alerts aligned with Pinchflat-ngx; internal module names and compatibility identifiers unchanged.
- **Long titles and mobile control layout:** very long source and media names stay readable on narrow viewports; edit, close, and fallback controls stay inside their panels (existing screens on `master` only).
- **Source cutoff diagnostics and support links:** cutoff date predicates, source detail edge cases, and fork support/README links corrected where they still diverged from merged fixes.
