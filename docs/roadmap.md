# Roadmap

We track larger enhancements here when they are not scheduled for an immediate release. GitHub issues remain the source of requests.

## Planned

### Global “Latest” media view ([#99](https://github.com/TheBadFella/Pinchflat-NGX/issues/99))

**Request:** A **Latest** tab listing recently indexed media across all sources, newest first, so you do not open each source to see what is new.

**Status:** Open. We have not scoped UI placement (Home vs Sources) or query limits yet. This needs a dedicated feature PR after the current quality and reliability batch.
